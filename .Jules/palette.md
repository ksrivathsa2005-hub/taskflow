## 2026-06-03 - [Login Form Accessibility & UX Enhancement]
**Learning:** Inline templates in this app often lack explicit `id` and `for` associations between labels and inputs, which can hinder screen reader navigation and click target size. Additionally, password fields benefit greatly from visibility toggles for better error prevention and confidence.
**Action:** Always ensure interactive elements in inline templates have unique `id`s and matching labels. Implement password toggles for all authentication forms to improve usability.
