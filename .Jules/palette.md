## 2026-06-08 - [Form Accessibility and Usability Patterns]
**Learning:** Combining `autocomplete` attributes with explicit `label[for]` and `input[id]` associations significantly improves the user experience for both screen reader users and those using password managers. Adding a visibility toggle for password fields reduces friction and errors during authentication.
**Action:** Always include `autocomplete` attributes on auth forms and ensure interactive icons (like visibility toggles) are keyboard-accessible with proper focus-visible states and ARIA labels.
