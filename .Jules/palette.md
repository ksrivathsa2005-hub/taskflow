## 2026-02-08 - [Accessibility Baseline in App Shell]
**Learning:** Even when a project has a "standard pattern" mentioned in memory (like Skip to Content links), it may be missing in the actual implementation. Universal components like Navbars often lack keyboard accessibility (using clickable divs instead of buttons) which impacts the entire application.
**Action:** Always verify the core app shell (`app.html` and Navbar) first for baseline accessibility before diving into page-specific UX improvements.
