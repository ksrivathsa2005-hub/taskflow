## 2026-04-09 - Accessibility Fundamentals: Skip Links and Semantic Navbar

**Learning:** Implementing a "Skip to Content" link and semantic interactive elements (converting `div` with click handlers to `button`) significantly improves keyboard navigability and screen reader support with minimal code impact. Ensuring a high z-index for the skip link is crucial when using sticky navbars.

**Action:** Always check for a skip link in the main layout and ensure branding/logos are semantic `<button>` or `<a>` tags instead of interactive `div`s.
