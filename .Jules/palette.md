## 2026-02-19 - Standardizing Global Accessibility
**Learning:** This application had several non-semantic interactive elements (like `div` with click handlers) and lacked basic keyboard navigation aids like a "Skip to Content" link. Providing these foundational a11y features significantly improves the experience for power users and those using assistive technologies.
**Action:** Always check for "Skip to Content" links and ensure that interactive elements use semantic HTML (`button` or `a`) with proper `focus-visible` styles and ARIA labels.
